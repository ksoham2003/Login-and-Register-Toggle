# React + Vite (Form Toggle Demo)

A minimal React + Vite project demonstrating a **Login / Register toggle** implemented using `useState` in `App.jsx`.

## ✅ Features

- **Register form shows by default**
- Toggle between forms using `useState` in `App.jsx` (not inside child components)
- Passes `setToggle` down as a prop to `Login` and `Register`
- Uses `setToggle(prev => !prev)` for seamless toggling without page reload
- Styled with **Tailwind CSS** (via `@tailwindcss/vite`)

---

## 🚀 Run locally

```bash
cd advancedJs/day10-formHandling
npm install
npm run dev
```

Then open the URL shown in the terminal (e.g. `http://localhost:5174`).
